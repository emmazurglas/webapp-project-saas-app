# CloudFlow - SaaS Landing Page

A modern, responsive landing page for a fictional SaaS product built with React, Vite, Tailwind CSS, and Lucide React icons.

## 🚀 Features

- **Hero Section** - Eye-catching hero with gradient background, CTAs, and social proof
- **Features Grid** - 6 feature cards with icons showcasing product capabilities
- **Pricing Cards** - 3 pricing tiers with highlighted "Most Popular" option
- **Testimonials** - Customer testimonials with avatar images
- **Footer** - Comprehensive footer with links, social icons, and legal information

## 🛠️ Tech Stack

- **React 18** - Modern React with hooks
- **Vite** - Fast build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework with @tailwindcss/postcss
- **Lucide React** - Beautiful, consistent icon library
- **Responsive Design** - Mobile-first approach with sm/md/lg breakpoints

## 📦 Installation

```bash
npm install
```

## 🏃‍♂️ Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

## 🏗️ Build

```bash
npm run build
```

Builds the app for production to the `dist` folder.

## 🎨 Design Features

- **Purple-Pink Gradient Theme** - Modern gradient color scheme
- **Dark Mode Support** - Built-in dark mode styling
- **Smooth Animations** - Hover effects and transitions throughout
- **Accessibility** - Semantic HTML and ARIA labels
- **Performance** - Optimized icons and tree-shaking

## 📱 Responsive Breakpoints

- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: 1024px+
